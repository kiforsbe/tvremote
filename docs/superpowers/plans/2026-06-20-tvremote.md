# TV Remote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Samsung TV remote HTML app that runs as a compact Electron window on Windows 11 (with background global shortcuts) and installs as a PWA on iPhone via a local HTTP server.

**Architecture:** A single `app/index.html` is the UI source of truth for both platforms. Electron's main process (`main.js`) loads it in a fixed 260×680 window, registers media key global shortcuts, and serves the `app/` folder over HTTP on port 3000 so iPhone Safari can install it as a PWA.

**Tech Stack:** Electron ^31, Node.js built-in `http`/`fs`/`path`, jimp ^0.22 (dev, icon generation only), vanilla HTML/CSS/JS.

## Global Constraints

- Window: 260×680px, not resizable
- HTTP server: port 3000, bound to 0.0.0.0
- Global shortcuts: media keys only (MediaPlayPause, VolumeUp, VolumeDown, VolumeMute)
- No service worker, no bundler, no build step
- No branded app shortcut buttons (Netflix, Disney+, etc.)
- Button touch targets: minimum 44×44pt (iOS HIG)
- Safe area insets applied to body padding (iPhone notch/home bar)
- Color palette: `--bg #0f0f0f`, `--remote-body #141414`, `--btn #1e1e1e`, `--btn-hover #2a2a2a`, `--text #e0e0e0`, `--text-dim #555`, `--power-red #c0392b`
- Remote body: 180px wide, border-radius 44px
- Nav ring: 116px diameter, dominant focal element
- `samsung_remote.html` (old file) is deleted in Task 3

```js
const Jimp = require('jimp');
const path = require('path');
const fs   = require('fs');

const OUT = path.join(__dirname, '..', 'app', 'icons');
fs.mkdirSync(OUT, { recursive: true });

async function generate(size) {
  const img = new Jimp(size, size, 0x141414ff);

  // Rounded-rectangle remote silhouette
  const cx = size / 2;
  const cy = size / 2;
  const bw = size * 0.55;
  const bh = size * 0.80;
  const br = size * 0.18;

  for (let y = 0; y < size; y++) {
    for (let x = 0; x < size; x++) {
      const ax = Math.abs(x - cx);
      const ay = Math.abs(y - cy);
      const dx = Math.max(0, ax - (bw / 2 - br));
      const dy = Math.max(0, ay - (bh / 2 - br));
      if (ax <= bw / 2 && ay <= bh / 2 && Math.hypot(dx, dy) <= br) {
        img.setPixelColor(0x2a2a2aff, x, y);
      }
    }
  }

  // Nav ring circle
  const ringR = size * 0.15;
  for (let y = 0; y < size; y++) {
    for (let x = 0; x < size; x++) {
      if (Math.hypot(x - cx, y - cy) <= ringR) {
        img.setPixelColor(0x1e1e1eff, x, y);
      }
    }
  }

  await img.writeAsync(path.join(OUT, `icon-${size}.png`));
  console.log(`  icon-${size}.png`);
}

(async () => {
  console.log('Generating icons…');
  await generate(192);
  await generate(512);
  console.log('Done.');
})().catch(e => { console.error(e); process.exit(1); });
```

## Task 5: Electron Main Process

**Files:**
- Create: `main.js`

**Interfaces:**
- Consumes: `app/index.html` (BrowserWindow), `app/` directory (HTTP server), `sendKey(key)` global in the renderer (global shortcuts via executeJavaScript)
- Produces: running Electron app on Windows; HTTP server on `0.0.0.0:3000` serving `app/`

- [ ] **Step 1: Create main.js**

```js
const { app, BrowserWindow, globalShortcut } = require('electron');
const http = require('http');
const fs   = require('fs');
const path = require('path');

const APP_DIR   = path.join(__dirname, 'app');
const HTTP_PORT = 3000;
const WIN_W     = 260;
const WIN_H     = 680;

const MIME = {
  '.html': 'text/html; charset=utf-8',
  '.json': 'application/json',
  '.png':  'image/png',
  '.js':   'application/javascript',
};

// Allow Samsung TV's self-signed WSS certificate
app.on('certificate-error', (event, _wc, _url, _err, _cert, cb) => {
  event.preventDefault();
  cb(true);
});

function startHttpServer() {
  http.createServer((req, res) => {
    const rel  = req.url === '/' ? '/index.html' : req.url;
    const file = path.join(APP_DIR, path.normalize(rel));

    // Prevent directory traversal
    if (!file.startsWith(APP_DIR + path.sep) && file !== APP_DIR) {
      res.writeHead(403);
      return res.end();
    }

    fs.readFile(file, (err, data) => {
      if (err) { res.writeHead(404); return res.end('Not found'); }
      res.writeHead(200, {
        'Content-Type': MIME[path.extname(file)] || 'application/octet-stream',
      });
      res.end(data);
    });
  }).listen(HTTP_PORT, '0.0.0.0', () => {
    console.log(`Remote available at http://<this-pc-ip>:${HTTP_PORT}`);
  });
}

function registerShortcuts(win) {
  const map = {
    MediaPlayPause: 'KEY_PLAY',
    VolumeUp:       'KEY_VOLUP',
    VolumeDown:     'KEY_VOLDOWN',
    VolumeMute:     'KEY_MUTE',
  };

  for (const [accel, key] of Object.entries(map)) {
    globalShortcut.register(accel, () => {
      win.webContents.executeJavaScript(`sendKey('${key}')`).catch(() => {});
    });
  }
}

app.whenReady().then(() => {
  const win = new BrowserWindow({
    width:     WIN_W,
    height:    WIN_H,
    resizable: false,
    webPreferences: {
      nodeIntegration:  false,
      contextIsolation: true,
    },
  });

  win.loadFile(path.join(APP_DIR, 'index.html'));
  startHttpServer();
  registerShortcuts(win);
});

app.on('window-all-closed', () => {
  globalShortcut.unregisterAll();
  app.quit();
});
```

## iPhone PWA Install (Manual — not a code task)

Once the Electron app is running on the Windows PC:

1. Find the PC's local IP: open PowerShell and run `(Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' } | Select-Object -First 1).IPAddress`
2. On iPhone, open Safari and navigate to `http://<that-ip>:3000`
3. Tap the Share button → **Add to Home Screen** → **Add**
4. The app icon appears on the home screen; launching it opens in standalone mode (no Safari chrome)

**Certificate workaround (first time only):**
1. In Safari on iPhone, tap the **"accept TV certificate"** button in the app's cert hint
2. A new tab opens to `https://<tv-ip>:8002` — Safari shows an untrusted certificate warning
3. Tap **Advanced** → **Proceed** (or equivalent in iOS 26)
4. Close that tab, return to the remote, connect — WSS will now succeed
