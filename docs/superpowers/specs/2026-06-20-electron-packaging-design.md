# Design: Electron Packaging — Standalone Build & Installer

**Date:** 2026-06-20  
**Status:** Approved

## Overview

Add `electron-builder` to the tvremote project so that `npm run dist` produces two Windows artifacts:

1. A proper **NSIS installer** (`TV Remote Setup 1.0.0.exe`) — installs to the user's AppData folder with no UAC prompt, creates a Start Menu entry and desktop shortcut, registers with Programs & Features for clean uninstall.
2. A **portable executable** (`TV Remote Portable 1.0.0.exe`) — runs in-place, no installation required.

The design is Windows-first but structured so macOS and Linux targets can be added later with no changes to the Windows config.

---

## Architecture

No structural changes to the project layout. electron-builder reads configuration from the `"build"` key in `package.json` and bundles the existing source files into an Electron distribution. The only additions are:

- `electron-builder` devDependency
- `png-to-ico` devDependency (for `.ico` generation)
- `"build"` config section in `package.json`
- Two new npm scripts (`dist`, `pack`)
- `build/icon.ico` (generated, committed to git)
- `dist/` output directory (gitignored)

---

## Components

### 1. Icon (`build/icon.ico`)

electron-builder requires a `.ico` file for Windows builds. The existing `scripts/generate-icons.js` is extended to also produce `build/icon.ico`, a multi-resolution ICO embedding sizes: 16, 32, 48, 64, 128, 256 px. It uses the existing `jimp` devDependency to render each size and the new `png-to-ico` devDependency to pack them into an ICO binary.

Running `npm run icons` regenerates both the PWA PNGs and the Windows ICO. The ICO is committed to git so that CI or other contributors can run `npm run dist` without re-running the icon script.

### 2. electron-builder config (in `package.json`)

```json
"build": {
  "appId": "com.kiforsbe.tvremote",
  "productName": "TV Remote",
  "icon": "build/icon.ico",
  "files": [
    "main.js",
    "preload.js",
    "dialog-preload.js",
    "ip-dialog.html",
    "app/**"
  ],
  "directories": {
    "output": "dist"
  },
  "win": {
    "target": [
      { "target": "nsis",     "arch": ["x64"] },
      { "target": "portable", "arch": ["x64"] }
    ]
  },
  "nsis": {
    "oneClick": true,
    "perMachine": false,
    "createDesktopShortcut": true,
    "createStartMenuShortcut": true,
    "shortcutName": "TV Remote"
  }
}
```

- `oneClick: true` — installs silently per-user (AppData), no UAC prompt required.
- `perMachine: false` — user-scope install; no admin rights needed.
- `files` is explicit to exclude `tests/`, `scripts/`, `docs/`, `playwright.config.js`, `test-results/`.

### 3. npm scripts

| Script | Command | Purpose |
|---|---|---|
| `dist` | `electron-builder` | Full build: NSIS installer + portable |
| `pack` | `electron-builder --dir` | Package only (no installer); fast, for testing the bundle |

### 4. `.gitignore`

Add `dist/` so build artifacts are not committed.

## Build Output

After `npm run dist`:

```
dist/
  TV Remote Setup 1.0.0.exe     ← NSIS installer
  TV Remote Portable 1.0.0.exe  ← Portable executable
  win-unpacked/                 ← Unpacked app directory (used internally)
```

---

## Cross-platform Readiness

The `win` key in the build config is isolated. Adding macOS (`mac`) or Linux (`linux`) targets later requires only adding those keys — no changes to the `files` list, scripts, or any other existing config. The `build/icon.ico` is Windows-only; macOS would need an `.icns` and Linux a `.png`, which can be generated by the same icon script when needed.

---

## Out of Scope

- Auto-update (electron-updater) — not needed for a personal tool
- Code signing — optional, can be added later; unsigned installers work fine locally
- macOS / Linux targets — architecture is compatible, not implemented yet
